# ELHARIKA Electrical Designer 3D — RC3

RC3 continues the real electrical-installation focus and polishes the tablet studio UI.

## RC3 changes
- Independent visibility toggles for every electrical circuit in Real3D.
- Searchable component library.
- Responsive left/right tablet panel widths.
- Added Plans shortcut in the professional top toolbar.
- Electrical demo house refined with wall-hosted sockets, switches, two-way switches, junction boxes, doors/windows and cleaner routes.
- Demo resets Real3D to Balanced quality and shows all circuits.
- Added app icon and linked backup/data-extraction rules.
- Removed forced landscape manifest lock; activity remains resizable for modern tablets.
- Dark system/status/navigation styling aligned to the studio shell.

## Build status
Local structural and asset validation can run here. Full Gradle Android compilation still depends on a runner that can obtain Gradle/Android dependencies.
