# Electrical Realism asset sources

The alpha3 scene remains fully functional using procedural Filament geometry. This file records vetted sources for the next GLB replacement pass.

## Preferred CC0 source

- Poly Haven — all assets are CC0.
- Recommended kit: `modular_pipes_plastic_01` for realistic plastic tubes, elbows, valves, clamps and fittings.
- Poly Haven public API may be used to obtain glTF/GLB-related files. If the live API is integrated into the product, the API terms require clear Poly Haven credit and a unique User-Agent.

## Current alpha3 policy

- No remote asset is required for the scene to render.
- Procedural electrical geometry is always the fallback.
- External models should only replace a procedural component after license, polygon count, material compatibility and scale are verified.
- Do not ship a downloaded Sketchfab model unless its individual license and attribution requirements have been recorded.
